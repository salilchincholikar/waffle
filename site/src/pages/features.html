Features

Everything a spreadsheet should do. Faster.

Waffle opens the files you already have — CSV, Excel, and more — and lets you edit them like a native Mac app, without the wait.

Tabs & Find

Every file, one window

Open files become tabs in a thin, browser-style title bar — not a pile of windows. Find sits right beside them and searches every open file at once.

  • Match case, whole cell and "in formulas" toggles, right in the field
  • Step through matches across tabs; Replace one or Replace All
  • Counts and highlights stay live as you edit, undo and redo
  • Move a tab to its own window, or merge windows back, from the Window menu

Speed

Huge files, instantly

A Rust engine stores each cell in 8–13 bytes and only the cells on screen are drawn. Files load in the background: the first rows appear in milliseconds and you can start working straight away.

  • First rows of a 10-million-cell workbook in about 25 ms
  • CSV files with any number of rows
  • Smooth trackpad scrolling at any size

Formulas

195 Excel functions, live

Formulas recalculate as you type, in dependency order, across sheets and named ranges — from SUM and XLOOKUP to IFS, TEXTJOIN, NETWORKDAYS and IRR.

  • Files saved by tools that leave results out open fully calculated
  • Anything unsupported keeps Excel's saved value, never an error

See every function

Saving

Saves change only what you changed

Most apps re-write the whole file when you save. Waffle copies everything you didn't touch byte-for-byte.

  • Charts, pivot tables, macros, images and themes survive untouched
  • In CSV, unchanged rows are copied exactly — 00123 stays 00123
  • Inserting rows or renaming sheets updates formulas, charts, tables and names

Clean-up

Tidy messy data in a click

The Clean Up menu fixes the things that eat an afternoon in other apps.

  • Trim extra spaces; remove empty or duplicate rows
  • UPPER, lower and Title case
  • Standardise dates and amounts — ₹1,23,456.78, (1,200), 500 DR
  • Split text into columns; sort and filter by value

Native

A real Mac app

Built with AppKit for macOS 26 — about 4 MB, with standard shortcuts, menus and document windows.

  • Open Recent, Finder "Open With", Revert to Saved
  • Dark mode, with an optional dark sheet that keeps your colours readable
  • Looks like Excel: fonts, fills, borders, number formats, merged cells, frozen panes, conditional formatting, table styles and images
  • No account, no network requests, and macros never run
