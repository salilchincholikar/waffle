FAQ

Questions, answered

Why use Waffle instead of Excel or Numbers?

For opening, checking and fixing spreadsheets, fast. Waffle opens a 10-million-cell workbook in a blink, keeps every file in one window as tabs, searches all of them at once, and saves without disturbing anything you didn't change. Excel is still the tool for pivot tables, charts and macros — and Waffle keeps all of those intact when you edit a file in it.

Is it really free?

Yes. Waffle is open source under the Apache License 2.0: free to use, share and modify, including at work.

Does Waffle send my data anywhere?

No. Waffle makes no network requests at all — no accounts, analytics or update checks. Your files never leave your Mac.

Will saving in Waffle break my Excel file?

That's the thing Waffle is most careful about. Parts of the file you didn't touch — other sheets, charts, pivot tables, macros, images — are copied byte-for-byte, and inserting rows or renaming sheets updates references everywhere. See how saving works for the details and the known gaps.

Does it run macros?

Never. Files with macros (.xlsm) open normally and the macros are kept in the file untouched, but Waffle doesn't execute them.

Why does macOS say it can't check Waffle for malicious software?

Apple notarization needs a paid developer account, which the project doesn't have yet. The code is public and every release is built from it by GitHub Actions. To open it the first time, use System Settings → Privacy & Security → Open Anyway — see Download.

Does it work on Intel Macs, older macOS, Windows or Linux?

Waffle needs macOS 26 or later on Apple Silicon. It's built with AppKit, so there's no Windows or Linux version.

How big a file can it open?

Memory is the limit: about 8–13 bytes per cell plus the text. A 10-million-cell workbook uses around 90 MB. CSV files can have any number of rows; Excel workbooks follow Excel's grid of 1,048,576 rows × 16,384 columns.

Which formulas are supported?

195 Excel functions, listed in the guide. Anything else keeps the value Excel saved.

Can I open .xls, .xlsb or .ods files?

Yes. They open as new workbooks, and saving writes a new .xlsx — the original file is never modified.

I found a bug. How do I report it?

Open an issue on GitHub, ideally with a small, anonymised file that shows the problem. Files that Waffle changed when it shouldn't have are the top priority.
