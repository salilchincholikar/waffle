Install

  1. Download Waffle-{{version}}-arm64.zip from the release page and open it.
  2. Drag Waffle into your Applications folder.
  3. Open it. The first time, macOS says it can't check the app for malicious software — Waffle isn't notarized yet.
  4. Go to System Settings → Privacy & Security, scroll down and click Open Anyway. You only do this once.

Prefer the Terminal? xattr -dr com.apple.quarantine /Applications/Waffle.app does the same as step 4.

Requirements

  • macOS 26 (Tahoe) or later
  • A Mac with Apple Silicon (M1 or newer)
  • About 4 MB of disk space; memory grows with the files you open (roughly 8–13 bytes per cell)

Build it yourself

xcode-select --install
curl https://sh.rustup.rs -sSf | sh
git clone https://github.com/salilchincholikar/waffle
cd waffle && make run
