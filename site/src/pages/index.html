Features

Everything you open a spreadsheet for. Nothing you wait for.

Instant, even when huge

Only the cells on screen are drawn, and files load in the background — the first rows appear in milliseconds.

Saves "as is"

Charts, pivots, macros and images you didn't touch are copied byte-for-byte. 00123 stays 00123.

Looks like Excel

Fonts, fills, borders, number formats, merged cells, frozen panes, conditional formatting and table styles.

Clean-up tools

Trim spaces, remove empty or duplicate rows, fix case, standardise dates and amounts, split text into columns.

Formulas that keep up

195 Excel functions recalculate as you type, across sheets and named ranges — even in files other tools saved without results.

Truly native

Built with AppKit: Open Recent, Finder "Open With", trackpad scrolling, and dark mode — optionally a dark sheet too.

Big files stay light

Cells take 8–13 bytes each, so a 200,000-row CSV scrolls as smoothly as a small one. CSV files can have any number of rows.

  • Leading zeros and exact values preserved
  • Unchanged rows written back untouched

Dark mode, down to the cells

The sheet stays white like paper by default. Turn on View ▸ Dark Sheet in Dark Mode and it goes dark too — with your file's colours kept readable.

Speed

Measured, not promised.

FileCellsFirst rows on screenWhole file loadedMemory
CSV, 1,000,000 rows × 20 columns (151 MB)20 M10 ms0.7 s~260 MB
Excel xlsx, 10,000 rows × 1,000 columns (62 MB)10 M25 ms1.7 s~90 MB

On an Apple Silicon Mac. You can scroll and work from the first rows; the rest loads in the background. An xlsx takes longer per cell than a CSV because it's compressed XML that has to be unzipped and parsed, while a CSV is plain text. Memory is the real limit: roughly 8–13 bytes per cell plus the text.

Open source

Yours to read, build and improve.

A Rust engine owns the data; a Swift/AppKit app draws only what's on screen. Files never leave your Mac — Waffle makes no network requests and never runs macros.

Build it

xcode-select --install
curl https://sh.rustup.rs -sSf | sh
git clone https://github.com/salilchincholikar/waffle
cd waffle && make run
